# CRM WDIH

Sistema de gestão comercial para agência de viagens.

## Funcionalidades

- Dashboard com KPIs
- Cadastro de clientes com data de nascimento
- Pipeline / Cotações
- Vendas
- Viagens
- Financeiro (Receitas e Despesas)
- Módulo de Milhas
- Configurações
- Backup e restauração

## Como usar

1. Extraia os arquivos em uma pasta.
2. Abra o `index.html` em um navegador moderno.
3. Os dados são salvos no `localStorage` do navegador.

## Estrutura

- `index.html` — interface principal
- `css/style.css` — estilos
- `js/` — módulos JavaScript

## Observação

Este é um sistema front-end. Para uso em produção, recomenda-se integração com back-end e autenticação.
